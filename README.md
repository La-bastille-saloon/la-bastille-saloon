# La Bastille

Registre de gestion du saloon. Ouvrir le site depuis GitHub Pages ou servir le dépôt avec un serveur HTTP statique.

Les modifications sont enregistrées automatiquement dans le navigateur. Dans **Paramètres → Sauvegarde des données**, on peut exporter le registre en JSON et réimporter ce fichier dans un autre navigateur. L’import valide le fichier avant de demander confirmation, puis conserve une copie exportable de l’ancien registre.
